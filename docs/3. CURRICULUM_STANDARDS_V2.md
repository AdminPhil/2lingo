## 🏗️ 1. The v2 5-Lesson Unit Arc Specification

Every Unit (`U1–U60` in Levels 1–3, scaling to `U100` in Levels 4–5) follows a uniform **5-lesson mastery arc** (`lessons.kind` enum in `db/schema.v2.ts`), eliminating all hardcoded `lesson.order === 4` checks:

| Lesson | `kind` Enum | Focus & Pedagogical Mechanism | Visuals (`imageSrc`) | Audio (`audioSrc`) | Target Challenges |
| :---: | :--- | :--- | :---: | :---: | :---: |
| **L1** | `DISCOVERY` | Visual & audio introduction of core unit vocabulary (`SELECT`). Every challenge renders 4 illustrated cards. | **ON (100%)** | `hr-HR-GabrijelaNeural` | 4 |
| **L2** | `PHRASE_LISTEN` | Auditory discrimination (`LISTEN`) + phrase/action comprehension (`ASSIST`). | **OFF (`null`)** | `hr-HR-GabrijelaNeural` | 4 |
| **L3** | `PRODUCTION` | Active Croatian sentence construction (`BUILD_SENTENCE`) + morphological minimal-pair `ASSIST`. | **OFF (`null`)** | `hr-HR-GabrijelaNeural` | 4 |
| **L4** | `SPIRAL_REVIEW` | Cross-unit & cross-world spaced reinforcement (`>= 40%` prior-unit items for `U2+`, mixed recall for `U1`). | **OFF (`null`)** | `hr-HR-GabrijelaNeural` | 4 |
| **L5** | `BOSS_CAPSTONE` | 👑 **Super Izazov** cumulative unit capstone rewarding the Golden Trophy Crown & **`+3 ❤️`**. | **OFF (`null`)** | `hr-HR-GabrijelaNeural` | 5 – 6 |

## 🎮 2. Six-Tier Cognitive Mechanic Ladder

CroLingo v2 replaces v1's flat `SELECT`/`ASSIST` schema with a polymorphic 6-tier challenge ladder (`challenge_type` enum):

| Tier | Type | Status | Pedagogical Role |
| :---: | :--- | :---: | :--- |
| **1** | `SELECT` | ✅ Active (v2.0) | Visual flashcard discovery (`L1 DISCOVERY` only, 4 illustrated cards + audio). |
| **2** | `ASSIST` | ✅ Active (v2.0) | Text + audio multiple choice; uses Deductive Elimination in L1–L2 and Morphological Minimal Pairs in W5+. |
| **3** | `LISTEN` | ✅ Active (v2.0) | Audio-only Croatian listening prompt (normal + 0.75× slow replay) without English translation crutches (`W2–W12 L2` & `L4`). |
| **4** | `MATCH_PAIRS` | ⏳ Deferred (v2.1) | Rapid 4–5 pair vocabulary matching. |
| **5** | `BUILD_SENTENCE` | ✅ Active (v2.0) | Interactive Croatian word-bank tile assembly with morphological distractor tiles (`W4–W12 L3–L4`). |
| **6** | `CLOZE` | ⏳ Deferred (v2.1) | Fill-in-the-blank case ending / verbal aspect drill. |

## 🎨 3. Progressive Scaffolding Fading Invariant

1. **Lesson 1 (`DISCOVERY`) — Images Strictly ON:**
   - Every challenge in Lesson 1 MUST be `type: "SELECT"`.
   - Every option in Lesson 1 MUST include a valid, non-empty `imageSrc` file on disk in `public/`.
   - Learners tap cards to hear Croatian pronunciation (`hr-HR-GabrijelaNeural`) attached directly to visual meaning before scaffolding fades.
2. **Lessons 2, 3, 4 & 5 (`PHRASE_LISTEN`, `PRODUCTION`, `SPIRAL_REVIEW`, `BOSS_CAPSTONE`) — Images Strictly OFF:**
   - `imageSrc` MUST be `null` / omitted on every option in Lessons 2–5.
   - Visual crutches are removed so learners retrieve Croatian via listening, reading, and sentence assembly.
   - `SPIRAL_REVIEW` (L4) and `BOSS_CAPSTONE` (L5) MUST NEVER carry picture giveaways.

---

## 🧠 4. Distractor Rigor, Deductive Elimination & Minimal Pairs

1. **Deductive Elimination (Early Worlds `W1–W4` & Net-New Words):**
   - Never test an unmastered word against 3 unfamiliar distractors.
   - Distractors for newly introduced text-only words must come from already-mastered vocabulary across distinct semantic categories.
2. **Morphological Minimal Pairs (Worlds `W5–W12+`):**
   - `>= 30–45%` of `ASSIST` challenges in Worlds 5–12 must test genuine Croatian grammatical contrasts (case endings like *u luku* vs *u luci*, tense contrasts *smo* vs *ćemo* vs *bismo*, negation, or gender/number agreement) rather than unrelated noun swaps.
3. **4-Option Grid Symmetry (`SELECT`, `ASSIST`, `LISTEN`):**
   - Exactly **4 options** per multiple-choice challenge (25% chance floor).
   - Uniform casing and identical ending punctuation across all 4 options (zero shape/punctuation giveaways).
   - Non-truncating labels (`break-words leading-snug`).

---

## 📈 5. Monotonic Complexity & CEFR Grammar Spiral

1. **Zero Complexity Dips:** Average Croatian word count (`AvgW`) must progress monotonically across Worlds (`W1 → W12+`), preventing regressions like v1's Worlds 7–8 dip.
2. **Sustained Grammar Spiral (No "Introduce Once, Abandon"):**
   - **Level 1 (`W1–W4`, `Pre-A1 → A1.1`):** Survival greetings, concrete nouns, present tense, spatial prepositions (`u`, `na`, `ispod`, `blizu`).
   - **Level 2 (`W5–W8`, `A1.2 → A2.1`):** Accusative motion vs. Locative state, Instrumental, *Perfekt* (W7), *Futur I* (W8).
   - **Level 3 (`W9–W12`, `A2.2 → Early B1`):** Sustained *Perfekt* + *Futur I* + *Kondicional I* (`bih/bi/bismo`) + subordinate clauses (`jer`, `dok`, `kada`, `koji`).
   - **Levels 4–5 (`W13–W20`, `B1.1 → B1.2`):** Verbal aspect pairs, complex narrative, and Half-Life Regression Daily Refresh (post-v2.0).

## 🔊 6. Audio Integrity Specification

- **Voice Standard:** `hr-HR-GabrijelaNeural` (Microsoft Azure / Edge Neural Croatian TTS).
- **100% Disk Coverage:** Every `audioSrc` referenced in YAML (all `SELECT`/`ASSIST`/`LISTEN` options and `LISTEN`/`BUILD_SENTENCE` prompts) must exist as a non-empty `.mp3` in `public/audio/hr/` before compilation.

## 🛡️ 7. Offline Compile-Time Quality Gates

Before any YAML change is compiled into Neon Postgres (`npm run v2:compile`), both offline gates must exit `0`:

| Gate Command | What It Enforces |
| :--- | :--- |
| **`npm run v2:validate`** | Zod schema validity for all Worlds/Lexicon/Grammar files, 5 lessons per unit (`L1`–`L5`), 100% `.svg`/`.mp3` file existence & non-zero size, L1 visual discovery invariant (`SELECT` + 4 images), L2–L5 progressive fading (`imageSrc === null`), 4-option symmetry, uniform casing & punctuation. |
| **`npm run v2:pedagogy`** | Overall Duolingo Alignment Score `>= 4.3 / 5.0`, **0 complexity dips**, W5–W12 minimal-pair share `>= 30%`, active 4-tier cognitive ladder (`SELECT`, `ASSIST`, `LISTEN`, `BUILD_SENTENCE`), and sustained tense/clause spiral across W7–W12. |
